# PsBash Release Notes Archive

Full, detailed release notes for every version. The module manifest
(`src/PsBash.Module/PsBash.psd1`) carries only condensed one-line summaries of
the most recent releases to stay under the PSGallery ReleaseNotes size cap; this
file is the complete history. See also the GitHub releases:
https://github.com/standardbeagle/ps-bash/releases

## v0.11.6

Fix (#7): ps-bash -c no longer piles up idle ps-bash-host processes under an AI agent. The warm background host now exits about 5 seconds after the shell or agent session that started it ends, instead of idling for 10 minutes; an agent that ran each command in a fresh shell used to leave one ~65 MB host per command. Warm reuse inside a live session is unchanged. New docs page The Host Daemon explains sessions, when the host exits, and PSBASH_SESSION / PSBASH_PER_INVOCATION / PSBASH_HOST_IDLE_SECS. Fix: a command that stops reading piped stdin early (yes | ps-bash -c 'head -n 1') no longer exits 125 with "host dropped the connection" on Linux/macOS. Fix: cd ~/dir works on Linux/macOS (the path after ~ was joined with a backslash). Fix: $HOME and ~ follow the calling shell's HOME when commands share a background host. Fix: release zips report the right version in ps-bash --version (a v0.11.5 zip said 0.10.19). New: on WSL, the first unknown command warns when Windows /mnt directories on PATH make command lookups slow, and says how to turn them off.

## v0.11.5

Fixes: mv and cp on Windows replace a destination that is read-only or in use - including a running program (mv new.exe app.exe) - as Linux does, instead of "Access to the path is denied"; a file another process truly holds open is reported at once, naming the process ("Device or resource busy (open in app.exe, pid N)"), with nothing changed; a directory moves across drives. A sourced file's output now streams in order. [[ $a == $b ]] treats an unquoted $b as a pattern, and [[ $PWD == /tmp* ]] matches after cd /tmp.

## v0.11.4

Fixes: unquoted $f.txt, $f:x and ${f}x, and quoted "${f}x" / "${f}_bak", now expand f and keep the suffix (they printed empty or named another variable); break N / continue N leave the right loop, and a break inside while read ... done < file no longer exits the whole script; case, [[ == ]] and [ = ] match case-sensitively like bash (shopt -s nocasematch supported) and case arms are tried in order; a sourced file's output reaches stdout, and source keeps the caller's $1.. (restoring them after source f args).

## v0.11.3

SAFETY: rm -rf "$unset" (an empty operand) no longer deletes the current directory's contents (data loss in 0.11.2); every command treats an empty path as missing. The host now survives hostile input (deep nesting, huge chains, brace bombs, catastrophic regexes, runaway recursion and memory, kill -9 $$): only that command fails, and every host exit is logged with a reason. Fixes: heredocs and parens inside "$(...)" (git commit -m "$(cat <<'EOF' ...)" with it's or :) failed to parse); set -e stops on any failing command; if/while conditions keep their output; || and && see return N; subshells no longer leak set -e, variables or shopt; >&2 obeys 2>/dev/null and 2>&1; 2> files are byte-exact; repeated redirects; a failed redirect never runs its command; grep/sed BRE \| \( \{ \+ \?; expr :; extglob in case and [[ ]]; literal and expanded /tmp paths agree; date +%N; concurrent commands in the codex sandbox; locked files report Permission denied.

## v0.11.2

fixes a v0.11.0 regression where every native command (git, wsl, tman...) hung under an agent shell tool whose stdin is open but never written: natives now get the shell stdin as a real OS pipe, and what they do not read stays for the next command. Also: cmd < /dev/null means empty input; cd/eval/source/read/set keep their redirects; declare/typeset -f/-F/-p implemented (no more type: -f: not found); command -v, type and which print bash names instead of Invoke-Bash* and follow bash exit codes; BASH_VERSION and --version report the real version instead of 0.8.0.

## v0.11.1

maintenance — zero compiler warnings in PsBash.Core.Tests (nullability, xUnit analyzers, platform attributes, a duplicate test case removed) and a much smaller agent instruction context.

## v0.11.0

GNU-parity release. One shared ordered argument parser now drives ~50 commands (bundles, --, unique-prefix long options, GNU usage errors; a real option ps-bash does not implement is refused with exit 2, never silently ignored). Shell semantics: pathname expansion is a shell step (echo *, for f in *, arrays), $(...) word-splits, : > f creates the file, env prefixes reach pipe stages, compound commands share stdin, the launcher forwards its stdin into -c. Binary-safe bytes end to end (cat of a binary file is byte-exact; printf '\351' | wc -c is 1). Commands: find (-printf, -perm, -user, -newerXY, -L ...), grep/rg/sed option sets, ls layouts and sorting, cut -c in bytes, split -n, sort -R/-z/-V suffixes, join -o/-e, uniq --group, cat -A, head/tail -v/-z/-F, wc --total, cp/mv -i/-t/-T/-b/--update, ln -r, tar member filters, GNU diff options, a new jq engine with --arg/-n/-e, awk getline/print redirection/functions. Streaming and memory: grep/sed/find/tail/awk/seq/redirect stream with bounded memory; the host frees output as it is sent. Host: warm nested daemons per depth, cached command-not-found index (missing command 9s -> 1s). Linux/macOS fixes. Intentional differences: docs/specs/intentional-differences.md.

## v0.10.23

Daemon stall fix, release-archive fix, and a transpiler correctness batch from a real-world .sh corpus sweep. Host: a command whose launcher died mid-flight kept running in the daemon while holding the process-wide execution gate, so every later command in that session queued behind work nobody would ever read — a launcher killed 2s into sleep 30 made the next command wait 30.9s; now 0.2s. Connections now detect client disconnect (EOF, on live duplex transports only) and cancel the abandoned command, and WorkerPool.DisposeAsync awaits in-flight warmers so no runspace outlives its pool. Packaging: every release archive since v0.9.1 shipped without System.Management.Automation.dll and failed every command with "ps-bash-host did not accept connections within 20s" — PrivateAssets=all on the Microsoft.PowerShell.SDK reference excluded the SDK runtime assets from publish. Fixed, and build.yml plus publish.yml now RUN the packaged archive (scripts/smoke-archive.ps1) before uploading, which no workflow previously did. Transpiler, every fix oracle-verified against bash: command substitution as an arithmetic operand, $(( $(date +%s) + 60 )); empty case-arm bodies no longer swallow their own terminator; [[ x =~ ^(a|b)$ ]] keeps its regex; array literals spanning newlines, and declare/readonly/local initializers, survive; here-strings on compound commands; single-item for-in; while read a b binds every name; [[ ( … ) ]] grouping; quoted test operands keep expansions live; compound commands as &&/|| operands; braced ${name} before a colon; nested quotes inside "$( … )"; $(<file). Runtime: POSIX bracket classes such as [[:digit:]] and [[:space:]] never worked in grep/sed/awk/rg and silently matched nothing — they are now translated for .NET; binder-swallowed-flag recovery no longer reads a different pipeline stage.

## v0.10.22

Arithmetic, compact-output, and host reliability fixes. Arithmetic substitution (`$((...))`), arithmetic commands (`((...))`), and C-style `for ((...))` clauses now use one typed parser and runtime evaluator, preserving Bash precedence and side effects across all three forms. This also fixes nested parentheses and positional/special parameters such as `$0`, `$1`, `${10}`, `$#`, and `$?` (including Bash's `$10` versus `${10}` distinction), while malformed arithmetic consistently reports a parse error. In compact-output mode, a successful `git add ... && git commit ... && git push` chain is summarized once as a combined operation; failures retain their diagnostic output. Host worker acquisition/startup failures now return a complete stderr response and nonzero exit instead of silently closing the connection.

## v0.10.21

Robustness & security batch from a four-subsystem code review (37 findings). Transpiler: expanding-heredoc command substitutions $(...) and backticks are now transpiled instead of executed as raw PowerShell (a quoting-seam code-execution leak), with backslash escapes honoured; quote-aware ${...} boundary scanning; brace-expansion items escaped via PsBuild; subshell input redirects (cmd) < file; and a class of parser crashes now emits a clean positioned error instead (lone here-string quote, out-of-range fd, for $i, empty redirect target, ${10000000000}, oversized brace tuples). BashArith hex/octal literals wrap at 64 bits instead of throwing. Cmdlets: the entire PowerShell common-parameter binder-collision cluster is resolved — every colliding short flag (cp/mv/rm -i, cat -A/-v, column -o/-c, tee -p, tree -p/-C, split -e/-C, strings -a/-e, grep -d/-D, sort -i, head/tail -v, du -P, uniq -w, readlink -e/-v, mktemp -p) now binds a decoy parameter so it no longer crashes the binder or silently drops, with the collision guard extended to catch the class mechanically; column -s with an empty separator no longer splits per character; tail -f withholds a partial final line until its newline arrives. Host/shell: Ctrl-C no longer races the prompt-loop token dispose into a process crash; Tab completion is deadline-bounded so it never hangs; the alias table is concurrency-safe; completion columns use display width; POSIX cwd tracking, scrollback preservation on a clean non-zero exit, and frecency-store disposal on the connection-lost path are fixed; ps-bash -c cmd --version now runs the command instead of printing the banner. Core/IPC: the stale-artifact reaper unlink race and a ModuleExtractor winner mis-handling are closed; the post-EXIT read is deadline-bounded; a persistent spawn-lock permission error degrades to an unguarded spawn instead of a 20s stall; compact output flushes a partial digest on a transport reset; a CommandNameCache lost-wakeup is fixed.

## v0.10.15

## v0.10.13

tar / gzip / sed / jq engine hardening (GNU/jq audit, all with regression tests). Security: tar extract refuses path-traversal (tar-slip / Zip-Slip) — escaping members (../x, absolute, drive/UNC) and escaping symlink/hardlink targets are no longer written outside the destination. tar --exclude is now an fnmatch glob (was a substring test; an empty --exclude= no longer drops everything); tar extract handles symlink/hardlink/directory entries; gzip -l size is 64-bit (no >2GB overflow); gzip force-deletes a read-only source. sed gains the numeric occurrence flag (s/x/y/2, /2g), the = and Q commands, address negation (2!d, /re/!cmd), step addresses (1~2), N,/re/ ranges (incl. 0,/re/), and the s///p flag; \n \t \r expand in replacements and \& is a literal ampersand (bare & is the whole match). jq: the // alternative streams every truthy value (was first-only); arithmetic needs no surrounding spaces (1+2, .foo-1, "a"+"b"); object construction is a Cartesian product over multi-valued fields ({a:(1,2)} streams two objects); computed keys {(expr):v} are evaluated; from_entries preserves insertion order.

## v0.10.12

Per-session host daemon (multi-agent contention fix) + a Tab-completion fix. The ps-bash-host daemon is now keyed per (user, session) instead of one shared daemon per user. Independent shells / agents each get their own warm daemon — the session token is the PSBASH_SESSION env var, or when unset the launcher's parent process id — so N concurrent callers no longer pile onto a single host and starve its warm runspace pool. That contention was the cause of multi-second-to-multi-minute stalls when many ps-bash -c invocations ran at once (e.g. several Claude Code agents sharing one machine, each command discarding its runspace and forcing the shared pool to cold-warm under CPU saturation). Repeated invocations from one shell still share a hot daemon (warm reuse ~0.2s); only independent sessions diverge, and each session's daemon is reaped by idle-shutdown. When no session token is available the historical per-user endpoint is used (back-compat). Tab completion: a command-position token containing a slash or ~ (./script, ../bin/x, dir/x, ~/x) now does filename completion over directories AND files — so ./sc<Tab> offers ./scripts/ — matching bash, instead of returning nothing (it previously scanned only files in the cwd and never directories).

## v0.10.9

Interactive shell features and runtime bug fixes. (1) cd - returns to the previous directory ($OLDPWD) and echoes it like bash; every successful cd now records $OLDPWD, and cd - with no prior directory reports "cd: OLDPWD not set" instead of failing on an empty path. (2) Bash history expansion in the interactive shell: !! (previous command), !n / !-n (by session index), !str / !?str? (prefix / substring search), the !$ / !^ / !* word designators and :n suffixes, and ^old^new quick substitution; expansion is suppressed inside single quotes and after a backslash, leaving the ! negation operator untouched. (3) ln -sf no longer destroys a populated directory tree: when the link name is a real directory the link is created inside it (basename of the target) and -f only removes a file or symlink, matching GNU ln (the old code ran a recursive delete). (4) awk file-operand mode: awk '{...}' file.txt now reads the named file(s) instead of silently dropping the operand and reading nothing. (5) kill fixes: named-signal short forms (kill -KILL / -TERM / -SIGTERM pid) are honored, and the pid loop no longer collides with the read-only $PID automatic variable, which silently broke every kill. (6) Stale-host fix: the daemon build identity now folds the host binary file stamp, so a recompiled host (same version, new code) replaces a running daemon instead of being silently reused. (7) Docs: new Interactive Shell guide and a Windows coreutils (uutils) comparison.

## v0.10.8

Robustness and interactive performance. (1) Interactive typing latency: keystrokes echo before the history/flag prediction runs, and prediction is fully async/debounced so a busy or IO-bound system never stalls input (set PSBASH_NO_PREDICT to disable it); the prompt is now drawn before the runspace finishes starting (startup type-ahead). (2) Hash-based transpile cache: startup .sh scripts transpile once and are cached on disk by content hash, with an in-memory LRU for repeated longer commands. (3) Bash-tool dogfood fixes: if/while/until conditions now test the command EXIT CODE rather than its output, so "if grep -q ..." and "if ! cmd" branch correctly; [ ... ] / test are silent (no stray True/False on stdout); every command resets the exit code on success (a trailing pwd no longer reports a stale 127); piping into "while read" now feeds the loop body; /dev/null as a file operand is an empty file instead of a crash; "cp -rf" bundled short flags are honored; and rm -rf / cp / mv / find -delete clear the read-only attribute so they no longer fail partway on Windows .git and node_modules trees. (4) grep gained --include / --exclude / --exclude-dir, -L/--files-without-match, -x/--line-regexp, -s/--no-messages, and -P/--perl-regexp. (5) "<cmd> --version" now identifies ps-bash across all commands. (6) Internals: emitted PowerShell is built through one shared builder and destructive filesystem operations through shared OS helpers, eliminating a class of one-off seam bugs (e.g. a negated-condition that took the wrong branch).
